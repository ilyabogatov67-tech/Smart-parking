# Smart Parking

Лабораторная работа по дисциплине
«Контейнеризация многокомпонентных приложений
с помощью Docker Compose».

Вариант №49 — Умная парковка.

## Описание проекта

Smart Parking — веб-приложение для учета
парковочных сессий и автоматического
расчета стоимости парковки.

## Возможности

- Расчет стоимости парковки по времени
- Сохранение парковочных сессий
- Просмотр истории парковок
- Отображение количества парковок
- Подсчет общей выручки
- Сохранение данных после перезапуска

## Технологии

- HTML, CSS, JavaScript
- Python Flask
- PostgreSQL 16
- Nginx
- Docker
- Docker Compose

## Архитектура

Приложение состоит из четырех контейнеров:

1. Frontend — интерфейс пользователя (Nginx)
2. Backend — REST API на Python Flask
3. Database — PostgreSQL
4. Web-service — расчет стоимости парковки

Взаимодействие:

Frontend -> Backend -> PostgreSQL

Backend -> Web-service

## Правила расчета

Стоимость одного часа: 100 рублей.

Неполный час округляется вверх.

Примеры:

- 30 минут — 100 рублей
- 60 минут — 100 рублей
- 90 минут — 200 рублей
- 150 минут — 300 рублей

## Запуск приложения

Необходимо установить Docker и Docker Compose.

Скачать проект:

git clone <URL-РЕПОЗИТОРИЯ>

Перейти в папку проекта:

cd smart-parking

Запустить контейнеры:

docker compose up -d --build

Открыть сайт:

http://localhost:8080

Проверить контейнеры:

docker compose ps

Остановить приложение:

docker compose down

Данные PostgreSQL сохраняются
в именованном Docker volume.

Для полного удаления данных
можно использовать:

docker compose down -v

Внимание: последняя команда удаляет
сохраненную историю парковок.

## API

GET /api/sessions
Получение истории парковок.

POST /api/sessions
Расчет и сохранение парковочной сессии.

Пример JSON-запроса:

{
  "plate": "A777AA77",
  "minutes": 150
}

## Особенности

База данных автоматически инициализируется
из файла db/init.sql при первом создании.

Web-service запускается как отдельный
локальный микросервис.

Для хранения истории используется
постоянный Docker volume.

## Назначение

Учебный проект для демонстрации работы
многокомпонентной архитектуры Docker Compose.

Пароли в docker-compose.yml предназначены
исключительно для локального учебного запуска.
